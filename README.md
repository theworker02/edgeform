# edgeform

Edge digests and form fingerprints for local integrity checks.

**Site:** https://theworker02.github.io/edgeform/

## Install / run

```bash
git clone https://github.com/theworker02/edgeform.git
cd edgeform
node src/cli.js
node --test
```
